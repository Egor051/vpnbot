# Первичная настройка («🧭 Первичная настройка»)

После `scripts/install.sh` бот работает без протоколов. **Первичная настройка** доводит
сервер до рабочего состояния — в Telegram, по шагам, тем, что бот уже умеет в других местах,
и никогда вторым способом.

🇬🇧 English version: [first-setup.md](first-setup.md)

## Когда предлагается

Сразу после успешного claim (`/start claim_<code>`, [install.ru.md](install.ru.md)), если на
хосте нет ни одного протокола, который ставит бот (`services/protocol_install.py`: ни Xray, ни
Hysteria2, ни SOCKS5 — или они только удалены), и первичная настройка ещё ни разу не прошла:
**🧭 Начать первичную настройку** / «Позже». В любой момент: «🧙 Мастер настройки →
🧭 Первичная настройка» — открытая настройка продолжается, а не начинается заново.

## Шаги

| Шаг | Что сначала проверяет | Что делает, если не так |
|---|---|---|
| домен | — | спрашивает домен сервера (вводится в чат) |
| токен | токен Cloudflare бота уже задан | спрашивает его; проверяет по зоне домена до сохранения — verify, чтение зоны, TXT-проба создаётся и удаляется ([certificate.ru.md](certificate.ru.md)); сообщение с токеном **удаляется сразу после чтения** |
| dns | домен резолвится в адрес этого хоста (`ip -4 addr show scope global`) | пишет A-запись → этот хост через DNS бота (`DnsService.upsert_a`, назначение `host`, proxied=false) |
| сертификат | сертификат бота покрывает домен (принят, ключ годен, 7+ дней) | прогон режима мастера `cert`: **принять** домен acme.sh с этим именем, иначе **выпустить** (DNS-01 токеном бота) |
| протоколы | — | суперадмин выбирает (☑️ VLESS REALITY и Hysteria2 по умолчанию, SOCKS5 предлагается); **✅ Продолжить** — ОДНО подтверждение всего дальнейшего, здесь же спрашивается TOTP, если он включён |
| установка | протокол уже на хосте | по прогону режима `protocol` на протокол ([protocol-install.ru.md](protocol-install.ru.md)) |
| ufw | — | `vpn-bot-ufw-apply apply` ([host-state.ru.md](host-state.ru.md)); смена входящей политики идёт под его собственным dead-man и подтверждается как обычно |
| totp | TOTP у суперадмина включён | обычное подключение (🔐 Включить TOTP), затем «▶️ TOTP включён», или «Пропустить» |
| самопроверка | — | прогон режима `selfcheck`; без красных пунктов настройка завершается **успешно** |

Прогоны сертификата и установок запускаются **подтверждёнными** (подтверждение — то, что
выше): их планы применяются сами; отчёт каждого прогона приходит отдельным сообщением, а
сообщение настройки отправляется заново под ним.

## Возобновляемость

Каждый шаг идемпотентен: сначала проверяет хост и сервисы и делает только недостающее.
Прогресс настройки — состояние каждого шага, домен, протоколы, прогон, который она ждёт, —
одна строка `wizard_runs` (режим `setup`; глобальный lock мастера она не держит: её шаги —
прогоны других режимов, которые его берут; схема не меняется). Установка перезапускает бота:
при старте открытая настройка находится и продолжается (startup-хук `WizardService`); прогон,
завершившийся тем временем, двигает её дальше (слушатель завершения `WizardService`). Шаг со
сбоем ждёт **🔁 Повторить** — он проверяет заново и при необходимости запускает новый прогон;
**✖️ Отменить настройку** завершает её. Токен, введённый в чат, не попадает ни в строку, ни в
лог, ни в аудит (только его отпечаток).

## Сквозной тест в CI

Джоб `setup-e2e` (`.github/workflows/ci.yml`, `tests/e2e/run_setup_e2e.sh`) проходит весь путь
на раннере ubuntu-24.04 с systemd: `install.sh` → claim → первичная настройка, которую ведёт
через мок Bot API `tests/e2e/drive_setup.py` (нажимает кнопки, которые показывает бот), с моком
Cloudflare API (`tests/e2e/mock_cloudflare_api.py`, `CLOUDFLARE_API_BASE`), домашним каталогом
acme.sh с сертификатом тестового CA, которому доверяет система (настройка его принимает), и
закреплёнными файлами релизов в кэше установщика (`/var/cache/vpn-bot-protocol-install` — файл
с именем ассета используется вместо загрузки, решает по-прежнему закреплённый sha256). Пока
идёт настройка, сеть **закрыта для root** (iptables по владельцу): nginx — из кэша apt, xray и
hysteria — из кэша релизов. В конце — настоящие юниты активны, self-steal отдаёт h2 с
сертификатом домена, у мока Cloudflare не осталось записей, самопроверка без красных пунктов.
